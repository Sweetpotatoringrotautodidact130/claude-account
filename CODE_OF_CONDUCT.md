# Code of conduct

We want this project to be a respectful and useful place to collaborate.

Participants must:

- Be respectful, constructive, and welcoming.
- Discuss ideas and code rather than attacking people.
- Avoid harassment, discrimination, threats, and publication of private
  information.
- Respect security reports and never request or publish real credentials.

Project maintainers may edit or remove abusive content and temporarily or
permanently restrict participation when necessary.

Report conduct concerns privately to the maintainer through the contact options
on the maintainer's GitHub profile. Reports will be handled as confidentially
as reasonably possible.
